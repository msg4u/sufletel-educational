# Suflețel — site de prezentare

Site static responsive pentru cele 8 module EdTech.

## Structură
- index.html — homepage
- style.css — design system
- module/*.html — cele 8 pagini individuale

## Utilizare
Deschide `index.html` într-un browser.

## Publicare
Poate fi publicat pe GitHub Pages, Netlify sau Vercel.

## Google Sites
Google Sites nu importă direct un proiect HTML ca site editabil nativ. Site-ul poate fi găzduit extern și apoi integrat în Google Sites prin Embed URL / iframe, în funcție de politica de embed a platformei.
